Saving on the website commits your changes to on GitHub. You need a GitHub account that has been added to the repo as a collaborator, and a personal access token:

  1. Open GitHub → new fine-grained token.
  2. Repository access: "Only select repositories" → pick this repo.
  3. Permissions → Repository permissions → Contents: "Read and write". Generate the token and copy it.
